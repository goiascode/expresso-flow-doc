# Pacotes e Agentes de IA

Todos os pacotes do ecossistema Expresso Flow são instalados via pip a partir do repositório oficial:

```bash
pip install --index-url https://exflow.run/simple <NOME_DO_PACOTE>
```

---

## Pacotes principais

| Pacote | Descrição |
|--------|-----------|
| `expresso-flow` | Core do framework |
| `exflow-webflow` | Interface web de debug e teste |
| `exflow-whatsapp` | Canal WhatsApp Business |
| `exflow-telegram` | Canal Telegram |
| `exflow-chatweb` | Widget ChatWeb embeddable |
