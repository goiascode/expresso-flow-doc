# Começando

Bem-vindo ao **Expresso Flow** — o framework Python para construção de fluxos conversacionais em múltiplos canais de comunicação.

Esta seção vai guiá-lo do zero até o seu primeiro fluxo funcionando.

## Pré-requisitos

| Requisito | Versão mínima |
|-----------|--------------|
| Python | 3.12+ |
| pip | 23.0+ |

!!! tip "Gerenciadores de ambiente virtual"
    Recomendamos o uso de [`venv`](https://docs.python.org/3/library/venv.html) ou [`uv`](https://github.com/astral-sh/uv) para isolar as dependências do projeto.
